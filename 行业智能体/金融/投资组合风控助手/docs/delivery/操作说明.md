# 操作说明

使用股票、基金和混合三个虚构组合。行情、舆情和接收人均为合成数据，输出供人工复核。页面顶部显示风险提示。部署环境见 [部署与复演](部署与复演.md)。

1. 打开「组合与持仓」，输入组合 ID、名称、类型、标的、成本、数量、持仓日期、止损和止盈，再保存。按原有 ID 保存会更新该组合。
2. 批量导入使用包含 `portfolios` 数组的 JSON 对象。可用 [演示三组合](../../data/demo.json) 查看结构。录入后按组合 ID 查询并核对持仓。当前页面提示也列出顶层数组，但服务端要求 JSON 对象，提交时使用对象格式。
3. 「Nexent 三工具联动」可直接运行固定的股票、基金和混合用例。价格回执通过核验后先显示价格结果，整条运行完成后会显示信号数及运行 ID。若要把刚录入的持仓传给同一个原生流程，先通过 `GET /api/portfolios` 按 ID 读回，再将 `id`、`name`、`type` 与持仓字段填入现有用例的 `case.portfolios`，更新 `knowledge_queries[].portfolio_id`，以新 `run_id` 调用 `POST /api/integrated-monitor`。请求使用 `mode=nexent-integrated`。录像通过演示脚本完成这一步并逐条回查实际参数。
4. 在「信号、推送与运行记录查询」按组合过滤信号，通过运行 ID 查价格、舆情和知识的业务记录。模拟网关在推送表标记「模拟」，可核对脱敏接收人、时间、状态和内容。若无可核验知识依据，按需复核。
5. 本地演示可注入模拟网关故障，生成失败记录后恢复网关并按事件 ID 重试。已成功发送的同一事件会去重，频率限制与失败/重试记录见 [调度与推送说明](../调度与推送交付_20261110.md)。真实接入见 [微信接入说明](微信接入说明.md)。
