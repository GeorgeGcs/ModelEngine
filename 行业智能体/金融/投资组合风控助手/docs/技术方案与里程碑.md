## 目标架构与责任分工

定时器按组合生成监控任务 → Nexent 主控创建运行记录 → 行情和舆情工具取数 → 价格及组合规则工具计算命中 → 信号研判结合知识库给出处和处置建议 → 微信 MCP 推送 → 看板按运行编号查询回执。

| 组件 | 职责与可核验证据 |
| --- | --- |
| Nexent 主控 | 编排组合任务，按有效数据、无命中、工具异常进入不同分支。使用同一运行编号贯穿工具调用、知识库检索、最终信号与网关回执。 |
| 行情与规则 | 按组合配置阈值和生效版本，采用十进制运算。扩展单日异动、集中度和流动性规则。缺失或过期行情标记为数据异常。记录标的、输入值、阈值、命中类型与行情时间，供人工复算。 |
| 舆情与信号研判 | 从舆情源取原文并保存依据；挂载分级标准、信号解释和处置建议知识库，留存检索条目与版本。模型可解释依据，数值命中、阈值和比较结果由规则工具确定。缺少依据时显式说明。 |
| 推送与追溯 | 实现 MCP 微信适配器、幂等键、限频、重试及回执查询。记录时间、内容、脱敏接收人和状态，区分已送达、失败、待确认、抑制及模拟回执。 |
| 前端与调度 | 支持手工录入和批量导入标的、成本、数量、持仓日期及止盈止损线，展示配置、趋势、信号和回执。调度记录应跑时隙、实跑时间、重试与人工补跑。 |
